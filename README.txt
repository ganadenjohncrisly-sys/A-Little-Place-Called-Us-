TWO COLORS, ONE STORY — WEBSITE FILES

To preview:
1. Keep index.html and the assets folder together.
2. Open index.html in a browser.
3. Tap “Enter our little world” to reveal the page and start the official YouTube embed for “About You” by The 1975.

Music note:
Phones and browsers block sound autoplay until a user taps something. The Enter button is that first tap. The song is streamed from the official YouTube video; an internet connection is required.

To publish online:
Upload index.html and the entire assets folder to a static website host (for example, GitHub Pages). Do not upload only index.html; the six photos are in assets/.
